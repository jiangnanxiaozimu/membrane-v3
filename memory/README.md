# 记忆（④）

膜的记忆分三层，**本目录是第三层「膜自身知识」**。

## 三层记忆

| 层 | 位置 | 内容 | 是否入库 |
|---|---|---|---|
| 数据团 | `store_db.py` → `membrane.db` | 记住每个页面长啥样（骨架 + 元素坐标），下次直接对上，不用重扫 | ❌ 运行时生成，`.gitignore` 排除 |
| 工作流 | `workflows` 表（graph_json） | 要执行的动作序列 | ❌ 数据，不入库 |
| 膜自身知识 | **本目录 `memory/`** | 设计决策 / 术语 / 已知坑 | ✅ 入库 |

## 铁律

本目录**只放理论知识和膜自身的记忆**，例如：

- 设计决策（为什么用真实鼠标不用 JS 模拟）
- 术语表（「数据团」「演员库」「骨架匹配」等）
- 已知坑（视口偏移、弹窗遮罩等，见 `WORKFLOW_LOGIC_V2.md`）

**绝不放**：

- 用户数据、操作记录（「点了千牛某按钮」「上了某商品」这类具体动作）
- 业务数据（商品 / 店铺 / 截图）
- 任何 API key / 账号 / Cookie

> 数据团（千牛页面元素）是**运行时生成物**，由 `scripts/crawl_*.py` 爬取重建，属于数据而非知识，不在本仓库。
